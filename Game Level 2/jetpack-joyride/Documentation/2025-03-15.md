Siendo media noche, continuamos con el código para manejar la pantalla, por ahora, aprendemos algo nuevo.

Además de manejar una resolución de `640x360` en Godot 4.4, se debe de continuar lo siguiente para controlar la resolución de forma correcta, para esto, seguimos los pasos, vamos a `ProjectSettings -> Display -> Window -> Stretch`. También, asignamos el modo y el Aspect: `Mode -> Viewport`, `Aspect -> Keep`. Manteniendo el aspect ratio y agregando bordes negros si es necesario.

Además, luego hacemos la prueba exportando el proyecto de Godot a Itch.IO para checar que tal queda.

Luego en exportar proyecto, vamos primero a descargar las plantillas de template de exportación el proyecto, en éste caso exportaremos a HTML, igual, mantenemos los stats iniciales como 640x360, y lo vamos a intentar subir en Itch.IO.

Acá marcamos igual lo de la vez pasada, pero ésta vez marcamos una opción extra, siendo dicha opción la siguiente: `'SharedArrayBuffer' support — (Experimental) This may break parts of the page or your project. Only enable if you know you need it.`

Agregamos sonidos y música y finalmente exportamos el proyecto
